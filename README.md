# Ghost Flyby

和不同時間騎同一條路的自己或別人，以幽靈車手（ghost）的身分同場重騎：把多個 GPX / FIT / TCX（可為 `.gz`）活動對齊到同一個起點同時出發，在地圖上重播，看誰先過終點。純靜態網站，檔案只在瀏覽器裡解析，不會上傳。

## 部署

把這個資料夾（`index.html`、`app.js`、`parsers.js`、`style.css`）放到任何靜態伺服器即可，例如：

```sh
python3 -m http.server 8000   # 然後打開 http://localhost:8000
```

`examples/` 裡有三組範例（西進武嶺 5 筆、環小台灣 2 筆、椰林盃 5 筆），在左側「範例」區按一下就能載入，不用自己上傳。範例是用 `fetch` 讀取的，所以必須透過 HTTP 伺服器開啟，直接雙擊 `index.html`（`file://`）會載入失敗。

Leaflet 從 unpkg 載入、底圖使用 OpenStreetMap 圖磚，所以瀏覽器需要能連網。

## 功能

- **自動對齊**
  - 對齊共同起點：在參考活動上找一個所有活動都經過、且每個人都最早到達的點（讓「誰騎最遠才到這裡」最小），經過時的行進方向必須和參考活動相同（逆著路線騎去集合點不算出發）；讓大家在 T = 0 時同時從該點出發（在起點停留、騎去起點的時間都會被剪掉，不會出現在重播中）；距離也從這裡開始算。適合同一路線不同天的比較，起點不同的環線也可以。
  - 同時出發：每個活動從各自離開起點的那一刻開始。
  - 實際時間：依真實時鐘重播，適合同一場團騎。
- **終點**：和起點對稱：從參考活動的終點往回找，取「每個人通過後再多騎的距離」最小、而且通過方向和參考活動相同的點當共同終點（逆著路線騎回去不算）；每個人騎完路線（沿路線距離已到終點前 500 m 內）後第一次同方向抵達該點就算完成；在終點附近停下又繞回來經過不會改變完賽時間，之後騎的部分不顯示。排行榜上完成的人依抵達順序排列，落後時間是與第一名的完賽時間差，不會被後到的人改變。
- **手動平移**：每個活動有一條拉桿（±最長活動時間）和秒數輸入框，疊加在自動對齊之上。
- **排行榜**（地圖下方，不會擋住地圖）：即時距離、落後時間（領先者多久以前經過你現在的位置）、時速（5 秒平均）；檔案有記錄的話，也顯示功率、心率、踏頻（3 秒平均）。沒有任何活動記錄的欄位會自動隱藏，個別活動沒有的顯示「—」。
- **距離**：每台裝置算的距離可能差很多（範例裡 2023 的碼錶多算了 8%），所以排行榜和圖表的距離都改用「沿參考活動路線的距離」：把每個活動投影到參考活動的軌跡上；離開路線的路段距離不增加。
- **小地圖**：地圖左下角顯示全部路線、每個人的位置，以及目前大地圖顯示範圍的框（放得很大時框會加上十字標記）；點小地圖可直接跳到該處。
- **全螢幕**：地圖、播放控制與排行榜一起全螢幕，地圖佔滿剩下的空間；按「離開全螢幕」或 Esc 離開。
- **觀賽模式**（預設開啟）：地圖鏡頭平滑移動並縮放，讓所有人都在畫面內；鏡頭會預判每個人接下來約 3 秒播放時間內要騎的路段，連同目前位置一起放進畫面，所以高倍速時顯示的是接下來要騎的那一段，而不是一味拉遠，地圖也不會快速掃過；鏡頭也會確保沒有人跑出畫面；拖曳、滾輪或按縮放鈕或按「縮放到全部路線」就會把鏡頭交還給你。
- **時間差圖**：以距離為橫軸，畫出每個活動相對參考活動快／慢幾秒。圓點是每個人目前的位置。
- **海拔剖面**：參考活動的海拔與每個人的目前位置；點兩張圖都能跳到該距離。
